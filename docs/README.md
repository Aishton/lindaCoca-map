# 项目文档

这里集中存放不适合塞进仓库首页的专题说明。运行入口仍保留在仓库根目录，以兼容 GitHub Pages。

## 文档导航

- [地图与位置数据](map/README.md)：地图技术结构、坐标来源、位置状态、人工圈点流程和维护检查清单。
- [角色与权限设计（用户与管理员）](roles-and-review.md)：用户与管理员分别能做什么、不能做什么，以及纠错提案的审核流程。
- [项目整体维护方案](maintenance.md)：团队分工、维护对象、发布与回滚、质量门禁、事故处理和交接清单。
- [数据库说明](../database/README.md)：SQLite 初始化、表结构和种子数据。
- [后端说明](../server/README.md)：本地 HTTP 服务和现有只读接口。

## 文档维护约定

- 新功能改变了使用方式时，同时更新对应专题文档和根目录 `README.md` 的功能摘要。
- 未实现的设计必须明确标记为“规划”，不要写成现有功能。
- 地点来源、确认状态和人工圈点规则以地图专题文档为准。
