# 觅食点 SQLite 数据库

在仓库根目录运行：

```powershell
node database/init.mjs
```

脚本使用 Node.js 24 自带的 `node:sqlite`，不需要安装 npm 包。它会生成 `database/meishi.sqlite`；重复运行不会重复插入同一批记录，修改 `seed.json` 后再运行会更新对应的种子字段，并保留审核状态等后续填写的字段。数据库文件已写入 `.gitignore`，四人协作时提交 `schema.sql`、`seed.json` 和 `init.mjs` 即可，每位成员本地运行一次初始化。

## 数据含义

- `places`：11 个食堂、1 个校医院对面窗口、9 个独立校内店铺、菘邻里及其 6 个子店铺，共 28 条。菘邻里的店铺用 `parent_id` 关联；集锦园条目中的驴打滚按“校医院对面的小窗口”单列，保留原清单出处。
- `recommendations`：39 条食物推荐；已给出的楼层写入 `floor`，未给出的留空。百景园的“水饺、馄饨”和“池奈、牛肉饭”分别拆成两条，原文保存在 `source_label`。
- `feedback`：预留给后端纠错反馈，目前没有任何预置反馈。

`source_group` 对应原始清单的“食堂／校内”。`source_label` 保留原条目。所有地点及推荐初始都标为“待确认”；校区、价格、餐次和最近确认时间未提供，数据库中保持空值。带有“减脂”“性价比”“肉多”“厨师发挥不稳定”等描述的是收集备注，不代表已经验证的事实。

当前 `index.html` 仍使用自身的模拟数据。此数据库完成了数据整理与存储，前端读取和反馈提交需要下一步接入 API。
